# D2P process mapping

[Open the live process maps](https://johndoe006767-commits.github.io/d2p-process-mapping/).

Explore the As Is and AI Suggested maps for eight finance towers, including their activities, handoffs, and improvement projects.

To run the site locally, double-click `start.command` on macOS or `launcher.bat` on Windows. From a terminal with Node.js installed, run `node scripts/start.mjs` and open the local address it prints.

GitHub Pages publishes the contents of `dist/` when changes reach `main`.
